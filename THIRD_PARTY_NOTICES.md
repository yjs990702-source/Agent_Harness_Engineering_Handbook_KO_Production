# Third-party notices

이 저장소의 직접 개발 의존성은 TypeScript 학습 코드의 검사와 테스트에만 사용됩니다.

| 패키지      | 용도                     | 라이선스 확인         |
| ----------- | ------------------------ | --------------------- |
| TypeScript  | strict typecheck와 build | package metadata 기준 |
| Vitest      | unit test                | package metadata 기준 |
| Prettier    | format 검사              | package metadata 기준 |
| tsx         | TypeScript fixture 실행  | package metadata 기준 |
| @types/node | Node.js type 정의        | package metadata 기준 |

정확한 버전은 `package-lock.json`을 기준으로 하며, 공개 라이선스 결정 전에 직접·전이 의존성의 고지 의무를 다시 확인합니다.
