# 공개 정책

## 공개 등급

- `PUBLIC`: 그대로 출판·배포 가능
- `GENERALIZE`: 문제와 교훈만 남기고 예제는 새로 작성
- `INTERNAL`: 조직 내부에서만 사용
- `REMOVE`: 불필요하거나 권리·개인정보 위험이 있어 삭제

## 판단 질문

1. 이 내용만으로 실제 개발 저장소나 운영 구조를 특정할 수 있는가?
2. 고객·직원·공동저자의 개인정보가 포함되는가?
3. 코드가 독립 작성인지, 제3자 라이선스와 출처가 확인되는가?
4. 학습자가 핵심 개념을 이해하는 데 꼭 필요한가?
5. 일반화된 더 작은 예제로 같은 목표를 달성할 수 있는가?

하나라도 불명확하면 공개하지 않고 `GENERALIZE` 또는 `INTERNAL`로 분류합니다.

## 저자 정보

저자명, 공개 GitHub 프로필, 합의한 출판용 약력만 `PUBLIC`입니다. 이력서 원본, 생년월일, 주소, 전화번호, 개인 이메일, 서명, 세부 증빙은 `INTERNAL`입니다.
