# 저자 소개와 기여 범위

## 김재환

저자·기획. 도서의 학습 목표, 하네스 엔지니어링 체계, 전체 커리큘럼과 출판 방향을 설계합니다.

## 윤재성

공동저자·실습 코드 공동개발자. Python·PyTorch·FastAPI 기반 AI/ML 시스템, RAG 파이프라인과 LLM 평가 데이터 구축, React/Node.js 기반 웹 풀스택, 데이터 분석·추천·수요 예측 분야의 개발 경험이 있습니다. AI 소프트웨어와 빅데이터 분석 장기 교육과정을 이수했습니다.

이 프로젝트에서는 다음을 담당합니다.

- 하네스와 멀티 에이전트를 중심으로 한 주차별 실습 공동 설계
- 공개 교육용 TypeScript 예제와 합성 fixture 공동 개발
- 설치·테스트·빌드·브라우저 시나리오 재현 검증
- 학습자가 사내 구현을 알지 못해도 따라갈 수 있도록 난이도와 설명 검토
- 공개 실습 저장소 운영과 코드·문서 최신화

GitHub: [yjs990702-source](https://github.com/yjs990702-source)

## 개인정보와 검증 원칙

위 약력은 공동저자 이력서에서 출판 목적에 필요한 기술 역량만 요약한 것입니다. 생년월일, 주소, 전화번호, 개인 이메일, 서명, 상세 근무일과 같은 개인정보는 도서·저장소·릴리스 문서에 싣지 않습니다. 소속·직함·학적 상태처럼 변할 수 있는 정보는 인쇄 직전 공동저자가 최종 확인합니다.

저자 표시의 최소 형식은 다음과 같습니다.

```text
지은이 김재환 · 윤재성
윤재성 — 공동저자·실습 코드 공동개발자
```

권리 귀속과 인세·출판 계약은 이 문서가 아니라 저자와 발행처가 체결한 최종 계약을 따릅니다.
