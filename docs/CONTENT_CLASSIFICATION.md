# 콘텐츠 분류표

| 항목                             | 등급       | 공개 처리                            |
| -------------------------------- | ---------- | ------------------------------------ |
| 하네스 계층과 역할 설명          | PUBLIC     | 일반 개념과 출처를 함께 제공         |
| TaskSpec·Evidence 교육용 schema  | PUBLIC     | 이 저장소에서 새로 작성              |
| 멀티 에이전트 DAG 예제           | PUBLIC     | 합성 과제·최소 구현만 제공           |
| SQLi·XSS 기본 방어               | PUBLIC     | parameter binding·text escaping 중심 |
| 실제 개발 구조·경로·SHA          | INTERNAL   | 언급하지 않음                        |
| 내부 모델 routing·평가 threshold | INTERNAL   | 원리만 일반화                        |
| 내부 승인·복구·감사 구현         | INTERNAL   | 세부 코드·schema 제외                |
| 실제 고객·운영 데이터            | REMOVE     | 합성 fixture로 교체                  |
| 저자 출판용 약력                 | PUBLIC     | 개인정보 제외                        |
| 이력서 원본과 연락처             | INTERNAL   | 저장소에 복사하지 않음               |
| 외부 논문·특허 원문              | GENERALIZE | 서지·링크·인용 범위 준수             |
| 오픈소스 코드                    | GENERALIZE | 라이선스 확인 후 인용 또는 재구현    |
