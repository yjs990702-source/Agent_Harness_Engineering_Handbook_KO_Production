# 미니 프로젝트: 안전한 문서 검색 하네스

## 목표와 시간

60~90분 동안 합성 문서만 검색하는 작은 에이전트 루프를 만듭니다. 새 프레임워크나 외부 API를 추가하지 않고 기존 모듈을 조합합니다.

## 요구사항

- `search_docs`만 registry에 등록합니다.
- 입력은 비어 있지 않은 `query` 문자열이어야 합니다.
- 모델 역할의 결정은 최대 4 step입니다.
- 미등록 도구·권한 상승·빈 query를 executor 전에 거부합니다.
- 사용자에게 보여 주는 결과는 브라우저에서 `textContent`로만 렌더링합니다.
- 정상 1개, 공격·실패 3개 이상의 테스트를 작성합니다.

## 권장 순서

1. `npm run lab:new -- mini-project`로 작업지를 만듭니다.
2. `minimal_loop.py`와 `tool_contract.py`의 테스트를 먼저 읽습니다.
3. 정상 입력 테스트를 작성하고 가장 작은 구현을 만듭니다.
4. 미등록 도구, 빈 query, 초과 권한 테스트를 추가합니다.
5. `npm run verify:all` 로그를 Evidence에 붙입니다.

## 합격 기준

| 축   | 기준                                |
| ---- | ----------------------------------- |
| 결과 | 정상 검색이 결정적 합성 결과를 반환 |
| 과정 | 제안→검증→실행→완료 event가 남음    |
| 안전 | 세 공격 입력이 executor 이전에 차단 |
| 비용 | step budget 4 이하, 외부 호출 0     |

## 심화 선택

승인이 필요한 `export_summary` 도구를 하나 추가하되 실제 파일 쓰기는 수행하지 않고, approval event와 dry-run 결과만 기록하십시오.
