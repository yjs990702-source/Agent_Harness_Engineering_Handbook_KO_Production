# 출판 전 검수 체크리스트

## 저자·권리

- [ ] 표지·판권·README에 `김재환 · 윤재성`이 동일하게 표시된다.
- [ ] 윤재성의 역할이 `공동저자·실습 코드 공동개발자`로 표시된다.
- [ ] 공동저자 약력에 연락처·주소·생년월일·서명이 없다.
- [ ] 코드·문서 라이선스와 제3자 고지가 확정됐다.

## 공개 경계

- [ ] 실제 개발 프로젝트의 URL·branch·SHA·경로가 없다.
- [ ] 내부 prompt·평가셋·threshold·고객 schema가 없다.
- [ ] 모든 fixture가 합성 데이터다.
- [ ] 코드 출처와 독립 작성 근거가 기록됐다.

## 교육 품질

- [ ] 핵심 3주 과정이 하네스와 멀티 에이전트에 집중한다.
- [ ] 웹·DB·클라우드 내용은 선택 부록으로 구분된다.
- [ ] 복사 가능한 코드가 저장소의 검증된 파일과 일치한다.
- [ ] 새 clone에서 `npm ci`와 `npm run verify:publication`이 통과한다.

## 원고 품질

- [ ] DOCX의 모든 페이지를 렌더링해 잘림·겹침·깨진 표를 확인했다.
- [ ] 제목 계층·표·그림 대체 텍스트와 페이지 전환이 정상이다.
- [ ] 기술 기준일·저장소 URL·버전·검증 수치가 최신이다.
