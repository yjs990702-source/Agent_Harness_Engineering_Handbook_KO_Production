# 코드 출처와 독립 작성 원칙

## 원칙

주차별 실습 코드는 도서 설명을 실행하기 위해 이 공개 저장소에서 새로 작성한 교육용 예제입니다. 실제 개발 프로젝트의 파일을 복사하거나 경로·이름만 바꾸어 공개하지 않습니다.

## 포함 가능한 출처 사용

- 표준 라이브러리와 공개 패키지 API 사용
- 공식 문서의 짧은 사용법을 바탕으로 독립 구현
- 논문·특허에서 문제 정의와 평가 관점을 요약
- 오픈소스는 라이선스·저작권·변경 여부를 확인한 뒤 필요한 범위만 사용

## 기록 단위

새 예제나 외부 코드를 추가할 때 PR 또는 handoff에 다음을 기록합니다.

- 작성자와 검토자
- 새로 작성/변형/인용 여부
- 출처 URL·버전·라이선스
- 포함한 코드 범위와 변경 사항
- 실행한 검증 명령

현재 직접 의존 패키지는 `package-lock.json`, 사람이 읽는 고지는 `THIRD_PARTY_NOTICES.md`에서 관리합니다. 프로젝트 자체 라이선스가 확정되기 전에는 `LICENSE_DECISION_REQUIRED.md`를 유지합니다.
